GEOINT on your MacBook

Your existing GEOINT extension, including place autocomplete, flags, maps, clocks, and reference data. Installation takes a few minutes. No Terminal commands, server, subscription, or API key are needed.

1. Transfer the ZIP to your Mac

On Windows, the delivery is saved inside:

C:\Users\andre\OneDrive\Documents\CASE PREP\deliveries

If this folder is syncing with OneDrive, wait for the upload to finish, then sign in to the same OneDrive account on your Mac and download the newest GEOINT-Mac-…zip. You can also copy that ZIP using a USB drive or a file-sharing service you already use. Transfer the whole ZIP.

2. Extract and keep the extension in a permanent folder

  1. In Finder, double-click the downloaded ZIP to extract it.
  2. Open the extracted delivery folder. It contains this guide and a folder named GEOINT.
  3. In Finder, open your home folder (Go → Home). Create a folder named Browser Extensions.
  4. Move the GEOINT folder into Browser Extensions.

Your final location should look like /Users/YOUR-MAC-USERNAME/Browser Extensions/GEOINT. Inside GEOINT, you should see manifest.json, dashboard.html, and the assets, data, and icons folders.

Chrome reads the files from this folder. Keep it in place after installing. The ZIP can be kept as a backup. If using a cloud-synced folder instead, make sure every file stays downloaded locally.

3. Install in Google Chrome

  1. Open Google Chrome on your Mac.
  2. Type chrome://extensions in the address bar and press Return.
  3. Turn on Developer mode at the top right.
  4. Click Load unpacked.
  5. Select the permanent GEOINT folder containing manifest.json. Select the folder, not the ZIP or an individual file.
  6. Find GEOINT in the extensions list. Open Chrome's puzzle-piece Extensions menu and pin GEOINT.
  7. Click its black-and-orange corner-bracket icon, then OPEN GEOINT.

This follows Chrome's official Load unpacked installation procedure. You do not need to publish to the Chrome Web Store for this personal installation.

4. First-use check

  • The initial location should be Coronado Island, California.
  • Type San Diego. The suggestion should include the U.S. flag. Press Tab to fill, then Return to search.
  • Search Jordan. Check that the satellite map, clock, and briefing show Jordan.
  • Try the map arrows and Intel / GEOINT / History side-panel pages.
  • Click the camera button while the map is visible. Look in Chrome's downloads list and your configured Downloads folder for the PNG.

What carries over?

The app's current code, datasets, autocomplete list, logos, flag images, silhouettes, and styling are included. Windows search history and cached locations live in that browser's private extension storage, so they are not included or synced. The Mac starts its own history.

Home Time stays fixed to Los Angeles / San Diego, even when you travel. Location Time follows the searched place. Live maps, weather, geocoding, and timezone lookup require an internet connection.

Some heading and clock fonts may differ on macOS because the preferred fonts are not bundled. Core functionality does not depend on those fonts.

5. Updates from Windows

  1. After editing the Windows project, create a new delivery ZIP using py tools/build_mac_delivery.py on Windows, or ask your coding assistant to rebuild the Mac delivery.
  2. Transfer and extract the new ZIP on the Mac.
  3. Close open GEOINT dashboard tabs. Back up your current GEOINT folder outside the installation path if desired.
  4. In Finder, copy the new GEOINT folder into the same Browser Extensions folder and choose Replace when asked. Keep the final path identical.
  5. Open chrome://extensions and click the circular Reload button on GEOINT. Then reopen GEOINT.

Use Reload for updates rather than removing and reinstalling the extension; this preserves the existing installation and its local history. Updates are manual. Editing the Windows copy does not automatically update this Mac copy.

Troubleshooting

  • “Manifest file is missing”: select the inner GEOINT folder, the one with manifest.json directly inside it.
  • Old toolbar icon: reload GEOINT from chrome://extensions, then reopen the popup.
  • No autocomplete or flags: replace the complete folder, including country-autocomplete.js, data, and assets. Reload the extension.
  • Blank maps: check your internet connection, give the provider a moment, and try the same location again. Network filtering may affect individual providers.
  • Screenshot unavailable: open GEOINT through its toolbar icon in Chrome, rather than double-clicking dashboard.html in Finder. Capture the map while its tab is active and visible.
  • Load unpacked is unavailable: a work/school-managed Chrome profile may restrict developer extensions. Use your personal Chrome profile where permitted.

This package contains the extension source and bundled assets. Raw dataset archives, separate desktop utility projects, and Windows launcher scripts are excluded. Mac installation has to be completed on the Mac; generating the delivery does not install it remotely.
